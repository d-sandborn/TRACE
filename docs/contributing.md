# Contributing to TRACE

Contributions to TRACE are welcome! If this is your first time contributing to a Github repository, please consider reading [this first](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project). 

## Ideas, bugs, issues

If you have a feature idea for TRACE or if there is a possible bug, let us know! First [open an issue here](https://github.com/d-sandborn/TRACE/issues). Somebody else may have had the same problem, and we want to avoid duplicating work.

## Changing code

Please make a fork of TRACE, make your changes, and submit it as a pull request. This makes it easy to compare versions line-by-line and to ensure the internal tests are working. 

### Credit
